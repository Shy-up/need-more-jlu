# need_more_jlu - 吉林大学校园网现代阅读增强插件 (Chrome Extension)

专为吉林大学师生打造的校园网及 OA 通知现代界面重塑与效率增强 Chrome 插件（Manifest V3）。

---

## 🌟 核心功能

1. **界面全面现代化重塑**：
   - 彻底隐藏 2000 年代传统门户的巨型装饰横幅（Banner）、多级冗余行政顶栏与底部大面积占位表格。
   - 采用现代化流体卡片排版（Card UI），最大化利用宽屏阅读空间，信息层级清晰明了。

2. **新旧通知秒级辨别（解决信息杂乱痛点）**：
   - **已读/未读状态追踪**：未读通知带有专属呼吸高亮指示灯与加粗醒目标题；已读通知自动转为柔和灰度与降低透明度，告别肉眼重复甄别。
   - **时间线智能分组**：列表自动切分为 **「🔥 今日最新发布」**、**「⭐ 昨日发布」**、**「📅 近 3 天发布」** 与 **「⏳ 早期历史通知」**。
   - **一键过滤**：顶部提供「只看未读」、「仅看今日发布」快速切换，并支持「一键全标为已读」。

3. **学生专属视角与分类**：
   - 告别退休认证、教工评职称等行政公文干扰。
   - 内置 **「🎓 教务与学籍」**（本科生院/研究生院/选课/推免）、**「🏆 奖助与学工」**（学工部/武装部/奖助学金/评优）、**「💼 就业招聘」**、**「🏃 体育生活」** 快捷分类标签。

4. **背景与主题深度自定义**：
   - **4 套精心调校的预设主题**：
     - ☀️ **现代极简浅色**：清爽微渐变、毛玻璃质感。
     - 🌙 **暗夜极客深色**：OLED 护眼深灰黑，自习室/夜间阅读不刺眼。
     - 📜 **护眼羊皮纸**：温暖纸墨色温，长时间阅读舒适。
     - 🎓 **经典吉大深蓝**：吉大标志性深蓝学府风采。
   - **支持本地壁纸上传与网络壁纸**：
     - **本地文件上传**：设置页支持**点击选择或直接拖拽本地图片（JPG/PNG/WEBP）**，自动转存为高效 Base64 持久化保存在浏览器本地（声明了 `unlimitedStorage` 无容量上限），无需搭建图床。
     - **网络图片 URL**：同时支持输入任意外部高清图链接。
     - 自动配合毛玻璃与半透明卡片呈现高颜值桌面级质感。
   - **自定义强调色（Accent Color）**：支持调色盘任意选择。

5. **抽屉式（Side Drawer）正文秒开预览**：
   - 点击任意通知，无需在 WebVPN 下反复新开标签页等待缓慢重载。
   - 页面右侧即时滑出阅读抽屉，自动提取排版正文并直接列出 **「📎 附件一键下载」**。

6. **本地星标收藏（⭐️）**：
   - 遇到重要的推免、评奖评优或活动通知，点击星标即可永久收藏，Popup 弹窗随时查阅，不怕被后续通知刷走。

## 🛠️ 安装与使用教程（离线加载）

1. 打开 Google Chrome 浏览器（或 Edge / Brave / Chromium 内核浏览器）。
2. 在地址栏输入 `chrome://extensions/` 并回车。
3. 在右上角开启 **「开发者模式」 (Developer mode)**。
4. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
5. 在弹出的文件选择器中，选中本项目目录：
   ```
   need_more_jlu
   ```
6. 安装完成后，即可在浏览器工具栏看到 `need_more_jlu` 的蓝色 JLU 专属图标！
7. 此时打开吉大 OA 校内通知页面（无论是通过 WebVPN 访问还是校内直接访问）：
   - WebVPN 模式：`https://vpn.jlu.edu.cn/https/.../defaultroot/PortalInformation!jldxList.action...`
   - 校内直连模式：`http://oa.jlu.edu.cn/defaultroot/PortalInformation!jldxList.action...`
   即可自动享受全新现代化的阅读体验！

```
│   ├── popup.html             # 浏览器右上角快捷控制面板
│   ├── popup.css
│   └── popup.js

│   ├── options.html           # 高级自定义设置页面（壁纸、强调色、数据管理）
│   ├── options.css
│   └── options.js

│   └── service_worker.js      # 后台生命周期管理

```

## 💡 提示与技巧

- **临时对比原始页面**：如果需要查看旧版原始表格布局，可随时点击右上角的「🔙 原始页面」按钮。
- **快捷键**：抽屉预览开启时，按键盘 `Esc` 键即可秒速关闭抽屉。
