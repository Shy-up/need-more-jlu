# need_more_jlu - 吉大自习仪表盘与校园网实用增强 (Chrome Extension)

专为吉林大学师生打造的自习直达仪表盘与官方 OA 渐进增强 Chrome 扩展程序（Manifest V3）。

---

## 🌟 核心功能矩阵

### 1. 核心高频：吉大自习直达仪表盘 (`/dashboard`)
彻底告别传统教务系统繁琐表单与盲人摸象式查空教室，实现空间直觉与安全感选座：
- **微观楼层选座热力图**：按真实建筑结构以楼层（1F、2F...）矩阵展示教室舱位，实时呈现全空（🟢）、中途有课（🟡）、满课（🔴）与封闭机房（⚪）；
- **连坐安全感指数**：直观展示当前教室可持续自习节次与下节上课时间；节次末期（距下课 ≤15 分钟）自动触发预警，避免入座即被赶；
- **全天 1~12 节走势卡片**：鼠标轻抚教室即时浮现迷你全天课表时间轴与建议停留时长；
- **场景时段预设**：支持“此时此刻立刻有座”、“上午自习 (1~4节)”、“下午自习 (5~8节)”、“今晚自习 (9~12节)”及 1~12 节多选点阵；
- **晚间真实闭馆提醒**：21:30 结课后如实提醒晚间闭馆锁楼时间不固定（通常在 22:00~22:30），避免滞留；
- **校内直连 + WebVPN 双通道**：校内连接校园网（JLU.PC / JLU.WLAN）可直连教务，校外自动适配 WebVPN 加密网关。

### 2. 轻量可靠：官方 OA 渐进增强工具箱 (`/content`)
严格遵循“渐进增强，不破坏原生”原则，零侵入、防漏报：
- **原网页保真侧边抽屉**：点击公文标题从右侧滑出阅读抽屉，100% 保持官方红头公文排版、印章与表格真实原貌，支持 Esc 键秒退与左边缘拖拽调整宽度；
- **极速附件下载栏**：抽屉顶部自动提取排版附件直链，一键点击下载；
- **「上次看到这里」隔离红线**：自动过滤置顶公文，在上次浏览截止处标出清晰红线，直观辨别最新发布内容。

## 🛠️ 安装与使用

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`；
2. 开启右上角 **「开发者模式」**；
3. 点击 **「加载已解压的扩展程序」**，选中本项目根目录 `need_more_jlu`；
4. 点击扩展图标即可进入控制面板，一键直达自习仪表盘或吉大 OA。

## 🤝 社区贡献：如何添加新校区/新教学楼

为方便全校各校区同学参与共建，本项目所有校区与教学楼数据已彻底解耦为**独立单文件存储**：

* 配置文件路径：[`data/campuses.json`](file:///b:/workspace/01_active/need_more_jlu/data/campuses.json)

### 添加教学楼步骤（零代码修改）
无需编写或阅读任何 JavaScript 代码，只需在 `data/campuses.json` 对应校区的 `buildings` 数组中添加一个 JSON 块并提交 Pull Request：

```json
{
  "id": "楼栋唯一ID",
  "code": "吉大教务系统该楼编码 (JXLDM)",
  "name": "校区-楼栋全称",
  "shortName": "显示简称",
  "tag": "楼栋标签",
  "totalFloors": 5,
  "description": "简要介绍"
}
```
保存后，自习仪表盘将自动载入新楼栋并在宏观看板与楼层图中实时渲染。
